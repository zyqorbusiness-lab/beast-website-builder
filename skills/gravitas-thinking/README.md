# gravitas-thinking

A model-neutral working discipline for AI coding agents on website builds,
adapted from [Gravitas](https://github.com/udaysharmadev/Gravitas) (MIT).
Start with [SKILL.md](SKILL.md). Paste-ready texts per model live in
[adapters/](adapters/): Gemini, Claude, ChatGPT, repo-reading coding agents,
and one prompt for any chat model.

These agreements make any model's work verifiable. They do not turn one model
into another model; no prompt can. Licence: MIT (see [LICENSE](LICENSE),
sources in [CREDITS.md](CREDITS.md)).
